【出力形式】
各候補の名前をキーとし、その値として評価項目のラベル名と対応する数値を値とするJSON形式で出力してください。数値は1から5の範囲である必要があります。

例：
```json
{{
  "候補Aの名称": {{
    "{label1_name}": 3,
    "{label2_name}": 4,
    "{label3_name}": 2,
    "{label4_name}": 5
  }},
  "候補Bの名称": {{
    "{label1_name}": 5,
    "{label2_name}": 1,
    "{label3_name}": 3,
    "{label4_name}": 2
  }}
}}
```
